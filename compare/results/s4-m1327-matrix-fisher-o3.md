# S4-M1327 — Matrix Fisher on O(3) with reflections

## Goal

Close the remaining matrix-directional gap: the full matrix Fisher
distribution on O(3), including the reflection component, with density

```
f(R) ∝ exp(tr(FᵀR)),   R ∈ O(3).
```

## Construction

O(3) splits into SO(3) and O⁻(3). With `S = diag(1, 1, -1)`:

- SO(3) component: matrix Fisher with parameter `F` (existing exact
  quaternion-Bingham sampler),
- O⁻(3) component: `R = R₀·S`, whose density is matrix Fisher with parameter
  `F·S` on SO(3).

The mixture weight is `Z_SO / (Z_SO + Z_ref)`, where each `Z` is the SO(3)
matrix Fisher normalizing constant. Via the quaternion reduction,
`Z(A) = ∫_{S³} exp(qᵀAq) dq`.

### Deterministic normalizer

`binghamNormalizerLog` computes `log Z` from the eigenvalues of the 4×4
Bingham matrix:

- eigenvalues are shifted by the maximum so the exponent is non-positive
  (no overflow),
- a 256-point Gauss-Legendre rule is generated by Newton iteration on the
  Legendre polynomial,
- the 2D integral uses the S³ decomposition `q = (u, √(1−u²)·v)` with the S²
  angle integrated in closed form through `I₀`, evaluated in log space via
  `logBesselI0`,
- the uniform case returns `log(2π²)` directly.

The weight error is about `2e-4` for eigenvalues up to ~100 and is deterministic;
sampling itself is exact conditional on the component.

### Sampling

`MatrixFisherO3(T)` draws a uniform `u`, selects SO(3) when
`u < soWeightValue()` and O⁻(3) otherwise, samples the corresponding
quaternion Bingham distribution, converts to a rotation, and flips the third
column for the reflection component. No burn-in or thinning is needed.

## Tests added (3 new, total 884)

1. **F = 0 is uniform on O(3)** — `soWeight = 0.5`; 20,000 samples have
   orthonormal rows/columns, `|det| = 1`, zero entry means within `±0.03`, and
   a positive-determinant rate of `0.5 ± 0.03`.
2. **F = 2I mixture weight** — the computed `soWeight` matches the exact 1D
   integral `Z_SO/(Z_SO+Z_ref)` (with `Z_SO = ∫√(1−w²)e^{−8(1−w²)}dw`,
   `Z_ref = ∫√(1−w²)e^{−8w²}dw`) within `1e-3`; the 20,000-sample
   positive-determinant rate matches within `±0.03`.
3. **General F and f32** — 2,000 f64 samples and 1,000 f32 samples are
   orthonormal within tolerance, and the f32 weight is finite.
